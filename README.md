# Проект документации

Этот проект позволяет автоматически генерировать документацию в формате DOCX из Markdown-файлов с использованием Pandoc.

## Структура проекта

- `MarkDown/` - папка с Markdown-файлами документации
- `MarkDown/figures/` - папка с изображениями
- `MarkDown/references.bib` - файл с библиографическими ссылками
- `Makefile` - файл сборки
- `README.md` - этот файл

## Зависимости

- Make (GNU Make)
- Pandoc (скачивается автоматически)
- LaTeX (TinyTeX, скачивается автоматически)

## Сборка

1. Убедитесь, что установлена утилита `make`.
2. В корневой папке проекта выполните команду:
   ```
   make
   ```

Это действие выполнит следующие шаги:
- Проверит наличие Pandoc и LaTeX
- Автоматически скачает и установит Pandoc, если отсутствует
- Автоматически скачает и установит LaTeX (TinyTeX), если отсутствует
- Соберет все Markdown-файлы из папки `MarkDown/` в один документ `documentation.docx`
- Включит изображения из `MarkDown/figures/` и обработает библиографию

## Очистка

Для удаления сгенерированных файлов выполните:
```
make clean
```

## Добавление новых файлов

Если вы добавите новые `.md` файлы в папку `MarkDown/`, они автоматически включатся в сборку при следующем запуске `make`.

## Вывод

Результатом сборки является файл `documentation.docx` в корневой папке проекта.
